# 바이브 창업 코치

AI로 서비스를 만드는 1인 초보 창업자가 고객 정하기부터 수익 계산까지 10단계를 진행하도록 돕는 Windows 프로그램입니다. 이름은 임시입니다.

읽는 자료가 아니라 실행되는 프로그램(.exe)이고, **사람에게 직접 연락하거나 인터뷰하라고 요구하지 않습니다.** 검증은 사람들이 이미 써 둔 글과, 올린 글·익명 설문·방문 기록의 숫자로 합니다.

## 지금 상태

첫 버전(0.1)입니다.

| 확인한 것 | 방법 |
|---|---|
| 판정 규칙, 글 붙여넣기, 네이버 검색 연동, 첫 화면 점검, AI 분류 | 자동 시험 8개 (네이버와 AI는 가짜 서버로 시험) |
| 10단계 화면 전체의 입력·저장·판정 흐름 | 리눅스에서 프로그램을 띄우고 브라우저로 끝까지 눌러 봄 |
| Windows에서 시험이 통과하고 .exe가 켜져 화면을 내보내는지 | `main`에 올릴 때마다 GitHub의 실제 Windows에서 자동 확인 |

| 아직 확인하지 못한 것 | 이유 |
|---|---|
| Windows에서 프로그램 창이 제대로 뜨고 보이는지 | 자동 확인은 창 없이 켜서 응답만 본다. 사람이 직접 열어 본 적은 아직 없다 |
| 실제 Claude 키로 AI가 답하는지 | 키 없이 가짜 서버로만 시험함 |
| 실제 네이버 검색 키로 글이 모이는지 | 위와 같음 |

## 쓰는 법

1. `VibeCoach.exe`를 받아 실행합니다. 설치는 없습니다.
2. 처음 실행하면 Windows가 "알 수 없는 게시자" 경고를 띄울 수 있습니다. 서명하지 않은 프로그램이라 그렇습니다. "추가 정보"를 누른 뒤 "실행"을 고릅니다.
3. 왼쪽 단계 목록에서 "지금" 표시가 붙은 단계를 진행합니다. 단계는 기록이 기준을 채우면 저절로 통과됩니다.
4. 설정에서 키를 넣으면 더 많은 일을 프로그램이 대신합니다. 둘 다 없어도 쓸 수 있습니다.
   - **Claude API 키**: 글 분류, 기획서, 글 초안을 프로그램 안에서 바로 받습니다. 없으면 지시문을 복사해 쓰던 AI에 붙여넣는 방식으로 동작합니다.
   - **네이버 검색 키**: 검색어만으로 지식iN·카페·블로그 글의 제목과 요약을 모아 옵니다. 없으면 찾은 글을 직접 붙여넣습니다.

기록과 키는 이 컴퓨터의 `%AppData%\VibeCoach` 폴더에만 저장됩니다. 키는 암호화하지 않은 파일로 저장되므로 남과 같이 쓰는 컴퓨터에서는 키를 넣지 마세요.

## 10단계와 프로그램이 해 주는 일

| 단계 | 프로그램이 해 주는 일 | 통과 기준 |
|---|---|---|
| 1 고객·문제 정하기 | 고객 한 문장 만들기, 너무 넓은 문장 경고, 좁히는 방법 제안 | 문장이 충분히 좁다 |
| 2 만들기 전 검증 | 고객이 이미 쓴 글 모으기, 분류, 문제와 표현 정리 | 실제로 겪고 해결하려 한 글 10건 |
| 3 기획·AI 지시 | 한 장 기획서, 코딩 도구에 줄 지시문 | 기획서가 있다 |
| 4 만들기 | 되돌리기 어려운 것 4가지 점검 | 점검 완료, 서비스 주소 있음 |
| 5 출시 준비 | 서비스 주소를 직접 열어 첫 화면 점검 10가지, 고칠 점 지시문, 방문 기록·익명 설문 붙이는 지시문 | 점검 실행, 준비 완료 |
| 6 알리기·첫 사용자 | 올릴 곳과 규칙 기록, 곳에 맞춘 글 초안, 방문을 세는 링크, 결과 기록, 댓글 답글 초안 | 글 2건 올림 |
| 7 검증·판정 | 세 가지 숫자로 계속·수정·근거 부족 판정 | 판정이 "계속" |
| 8 고치기·다시 오게 하기 | 설문에 적힌 불편 모아 보기 | 하나 고치고 재방문 장치 정함 |
| 9 수익 계산 | 방문 수로 광고 수익 계산, 목표에 필요한 방문 수 | 계산해 봄 |
| 10 운영·기록 | 비용 상한·백업 점검, 주간 기록 | 점검 완료, 기록 1건 |

통과 기준의 숫자(글 10건, 방문 30, "도움 됨" 3명 등)는 출발점으로 잡은 값이며 설정에서 바꿀 수 있습니다. 근거가 있는 값이 아닙니다.

## 폴더

| 위치 | 내용 |
|---|---|
| `app/` | 프로그램 코드 (Go). `app/web/`이 화면 (HTML, CSS, JS) |
| `app/build.sh` | 시험을 돌리고 `dist/VibeCoach.exe`를 만든다 |
| `.github/workflows/build.yml` | `main`에 올릴 때마다 실제 Windows에서 시험·빌드·실행 확인. `v0.1.0` 같은 태그를 올리면 내려받을 수 있는 릴리스를 만든다 |
| `docs/drafts.md` | 리서치 결론과 처음 구상 |
| `research/` | 수집한 자료 (유튜브, 한국 웹, 해외 웹) |
| `docs/archive/` | 문서 형태로 진행하려던 이전 계획. 지금은 쓰지 않는다 |

## 직접 만들기

Go가 깔려 있으면 됩니다.

```bash
sh app/build.sh
```

Windows가 아닌 곳에서 화면만 보려면 다음처럼 띄우고 출력된 주소를 브라우저로 엽니다.

```bash
cd app && go run . --no-window
```

## 고칠 때 지킬 것

이 프로그램의 대상은 낯선 사람에게 연락하는 일을 어려워하는 비개발자입니다.

- 1:1 연락, 인터뷰, 지인에게 부탁하기를 과제로 넣지 않는다. 허용되는 활동은 글 올리기, 달린 댓글에 답하기, 서비스 안의 익명 한 줄 설문이다.
- 단계의 통과는 사용자가 누르는 버튼이 아니라 기록에서 계산한다 (`app/judge.go`).
- 수익과 기간을 약속하는 문구, 출처 없는 숫자를 넣지 않는다. 법·세무는 판단하지 않고 확인할 기관만 적는다.
- 같은 글을 여러 곳에 뿌리기, 자동 게시, 규칙이 금지한 곳에 올리기를 돕는 기능을 넣지 않는다.
- 화면의 말은 쉬운 한국어로 쓴다. 용어를 써야 하면 그 자리에서 풀어 쓴다.
- AI 연결은 설정에 넣은 키만 쓴다. 컴퓨터에 따로 저장된 로그인 정보나 환경 변수를 쓰지 않는다 (`app/ai.go`).
