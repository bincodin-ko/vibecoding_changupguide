# 리서치 04 — 네이버 검색 API를 쓰지 않기로 한 이유

확인일: 2026-11-20 · 출처: 네이버 개발자센터 API 서비스 이용약관(https://developers.naver.com/products/terms/), 네이버 클라우드 NAVER API HUB 문서(https://api.ncloud-docs.com/docs/naver-api-hub-overview)

프로그램 0.1은 네이버 검색 API로 글의 제목과 요약을 가져와 저장하고 AI로 분류했다. 약관을 직접 읽어 보니 이 방식은 쓸 수 없어서 0.2에서 뺐다.

## 확인한 사실

| 항목 | 내용 | 출처 |
|---|---|---|
| 목적 제한 | 검색 API는 "애플리케이션 등에서 네이버 검색결과를 제공하기 위한 목적으로만" 쓸 수 있다 | 약관 2.1 |
| 가공 금지 | 받은 데이터를 "독립적으로, 가공 없이 노출"해야 한다 | 약관 2.2 |
| 저장 금지 | 데이터(가공·파생물 포함)를 "복사, 저장 또는 캐싱하는 행위" 금지. 예외는 기기에 24시간 또는 새 질의 시까지 | 약관 2.3, 2.4 |
| AI 금지 | "데이터를 AI에 입력하거나 학습, 개선, 평가 및 노출 등에 활용하는 행위" 금지 | 약관 2.3 |
| 신규 발급 중단 | 개발자센터의 검색 API 신규 신청은 2026-07-30 24:00에 중단. 기존 이용자는 2027-06-30까지 | 약관 부칙 제2조 |
| 이관 | 이후는 네이버 클라우드의 NAVER API HUB에서 발급. 주소와 인증 방식이 다르다(`naverapihub.apigw.ntruss.com`, `X-NCP-APIGW-API-KEY-ID`) | API HUB 문서 |
| 쇼핑 검색 종료 | 쇼핑·책·학술정보 검색 API는 2026-07-31에 종료, 기존 키도 사용 불가 | 약관 부칙 제2조 ③ |

## 확인하지 못한 것

- NAVER API HUB 자체의 이용약관과 요금. 안내 사이트가 자동 접근을 막아 읽지 못했다. 언론 보도는 같은 AI 활용 제한이 적용되고 유료 전환이 예고됐다고 전한다(미확인).
- 네이버 클라우드 가입에 결제 수단 등록이 필요한지.

## 그래서 바꾼 것

- 프로그램이 글을 가져오지 않는다. 검색어를 넣고 버튼을 누르면 사용자의 브라우저에서 네이버 검색(지식iN, 카페, 블로그)이 열린다.
- 사용자가 읽고, 근거가 될 글을 직접 복사해 붙여넣는다. 붙여넣은 글만 저장하고 분류한다.
- 키 발급이 필요 없어졌다.

## 할인 정보 사이트 운영자가 알아 둘 것

쇼핑 검색 API가 종료됐다. 상품 가격을 네이버 쇼핑 검색 API로 가져오는 방식은 더 이상 쓸 수 없다.
