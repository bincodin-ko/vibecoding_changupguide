# 수집·진행에서 빠진 것

수집일: 2026-11-19

## 접근하지 못한 자료

| 자료 | 상태 | 영향 |
|---|---|---|
| 유튜브 자막·설명 전문·댓글 | 개별 영상 페이지가 자동 접근에 응답하지 않음 | 영상 속 주장과 시청자 반응(댓글)을 직접 확인하지 못함. 제목·조회수·스니펫만 분석 |
| Reddit, dev.to, Product Hunt | 세션 네트워크에서 차단 | 웹 검색 요약으로만 확인. 수치 미검증 |
| Indie Hackers | 허용 목록에는 있으나 사이트가 자동 접근 차단 | 원문 미확인 |
| 브런치 | 허용 목록에 추가했으나 접속 실패 | 한국 창업자 후기 원문 미확인(검색 요약만) |
| 네이버 블로그·카페 본문, 디스콰이엇, 스레드, X | 차단 | 검색 결과의 제목·스니펫까지만 |

## 리서치 자체의 한계

1. **1차 자료가 없다.** 전부 남이 쓴 글과 영상이다. 실제 초보 바이브코딩 창업자 5~10명과의 대화가 가장 먼저 필요하다.
2. **정량 데이터가 없다.** 막히는 단계의 비율, 출시 후 사용자 수 분포 같은 숫자를 확인하지 못했다. 자주 인용되는 통계(실패 사유 42% 등)는 원문 확인이 안 됐다.
3. **경쟁 상품을 직접 써보지 않았다.** 국내 강의·부트캠프·전자책의 실제 커리큘럼과 가격, 해외 AI 코파운더 도구의 실제 품질을 확인하지 않았다.
4. **표본 편향.** 해커뉴스는 개발자 중심, 유튜브는 조회수가 나오는 주제 중심, 강의 판매 글은 성공 쪽으로 기울어 있다. 조용히 그만둔 사람의 목소리는 거의 잡히지 않는다.
5. **법·세무 정보는 미확인.** 사업자등록, 통신판매업, 개인정보처리방침, 제휴 고지 문구는 블로그 수준 자료만 봤다. 가이드에 넣기 전에 국세청, 공정거래위원회, 개인정보보호위원회, 각 광고·제휴 플랫폼의 공식 문서를 확인해야 한다.

## 아직 정하지 않은 것

- 대상: 비개발자인가, 사업을 모르는 개발자인가. 부업인가 전업인가.
- 이 가이드의 수익 모델과, 가이드 자신의 고객을 만날 채널.
- 운영 중인 할인 정보 사이트의 현재 숫자(방문자 수, 유입 경로, 재방문율). 첫 사례로 쓰려면 필요하다.
- 가이드의 이름과 말투. 강의 판매 광고처럼 보이지 않는 것이 중요하다.

## 다음에 보완할 수집

- 주요 영상 10~15개의 자막과 댓글(사용자 기기에서 직접 보거나, 접근 가능한 환경에서)
- 한국 채널별 홍보 규정 원문: 긱뉴스 Show GN, 디스콰이엇, 주요 네이버 카페, 커뮤니티 게시판 공지
- 국내 유료 강의 3~5개의 커리큘럼 비교표
- 초보 창업자 인터뷰 5~10건
